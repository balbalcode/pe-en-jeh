## 🎯 Tentang Repository Ini

Repository ini berisi **kumpulan materi pembelajaran** yang dibuat khusus untuk membantu kalian memahami konsep-konsep penting **sebelum perkuliahan dimulai**. Tujuannya? Supaya waktu di kelas lebih efektif dan kalian bisa fokus ke praktik dan diskusi yang lebih mendalam.

## 📖 Apa yang Bisa Kalian Lakukan?

| Aktivitas | Deskripsi |
|-----------|-----------|
| 📚 **Baca Materi** | Semua materi tersedia secara **gratis dan terbuka** untuk siapa saja |
| 📁 **Navigasi Mudah** | Materi disusun per minggu (`week-1`, `week-2`, dst.) untuk kemudahan akses |
| 💬 **Diskusi & Tanya Jawab** | Gunakan [GitHub Issues](../../issues) untuk bertanya apapun! |
| 🤝 **Belajar Bareng** | Kolaborasi dengan teman-teman sekelas |
| 🔍 **Eksplorasi Mandiri** | Belajar sesuai pace kalian masing-masing |

## 🎓 Filosofi Pembelajaran

> **"Perkuliahan bukan satu-satunya tempat belajar, tapi tempat untuk memperdalam yang sudah dipelajari."**

Dengan membaca materi ini sebelum kelas dimulai:
- ✅ Kalian datang ke kelas sudah punya **konteks**
- ✅ Diskusi di kelas jadi lebih **produktif**
- ✅ Lebih banyak waktu untuk **praktik** dan **problem solving**
- ✅ Bisa fokus ke **hal-hal yang belum jelas**

## 📂 Struktur Repository

```
materials/
├── sqa-4/
│   ├── week-1.md    # Konsep dasar SQA
│   ├── week-2.md    # (coming soon)
│   └── ...
├── general/
└── readme.md
```

## 💡 Cara Menggunakan Repository Ini

1. **📖 Baca materi** sesuai dengan minggu perkuliahan
2. **🤔 Catat** hal-hal yang belum jelas atau ingin ditanyakan
3. **💬 Buka issue** untuk diskusi atau bertanya (jangan malu!)
4. **🔄 Review** kembali setelah kelas untuk penguatan

## ❓ Punya Pertanyaan?

### 🚨 JANGAN RAGU UNTUK BERTANYA!

Seriously, **NO QUESTION IS A STUPID QUESTION**. Kalau ada yang:
- 🤷‍♂️ Kurang jelas dari materi
- 🐛 Menemukan typo atau error
- 💭 Ingin diskusi lebih dalam
- 🔧 Punya saran perbaikan materi
- 🆘 Butuh bantuan memahami konsep

**👉 [OPEN AN ISSUE](../../issues/new)** dan kita diskusi bareng!

> 💡 **Pro Tip:** Bertanya di issue juga membantu teman-teman lain yang mungkin punya pertanyaan yang sama!
